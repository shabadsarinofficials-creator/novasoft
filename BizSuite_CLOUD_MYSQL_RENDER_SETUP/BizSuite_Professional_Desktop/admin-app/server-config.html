Connect BizSuite

Connect this computer to your company's shared BizSuite server. Enter the server address provided by your administrator. You only need to configure this once per Windows account.

Office network example: http://192.168.1.25:8000
Replace the example IP with your server PC's real IPv4 address. For hosted services, use the secure HTTPS address supplied by your administrator.

1Make sure the shared server is running and this PC can reach it.
2Test the URL, save it, then restart BizSuite.
Security note: use HTTP only on a trusted private office network. Do not expose the sample server directly to the public internet.
