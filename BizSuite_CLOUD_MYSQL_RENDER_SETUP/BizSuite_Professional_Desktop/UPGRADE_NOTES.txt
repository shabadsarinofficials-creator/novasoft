BizSuite Task Center — complete fixed upgrade

SAFE INSTALL STEPS
1. Close BizSuite Admin, BizSuite Workspace, and the minimized BizSuite API window.
2. Make a copy of your current BizSuite folder before changing anything.
3. Extract this ZIP to a NEW folder.
4. Copy your existing backend\bizsuite.db and backend\jwt.secret into the new folder's backend directory. If your existing installation stores them elsewhere, preserve the exact existing files and locations.
5. Do not copy old main.py or old HTML files over the new ones.
6. Run the new run.bat. Keep its API window running.
7. Test with a dummy task before using important company data.

WHAT CHANGED
- Rebuilt Manager/Employee workspace actions using delegated click and form handlers to avoid stale buttons after screen redraws.
- Task Center: assignments, priorities, deadlines, status changes, comments, history, reference files, URL/ZIP submissions, version history, manager feedback, approval and resubmission.
- Notifications: task updates, comments, reviews, and submissions.
- Messages: direct messages, announcements, meeting notices with scheduled time, and optional acknowledgement tracking.
- Calendar, search, task reports, CSV export, Admin reports, and a downloadable SQLite + uploads backup ZIP.
- Admin remains read-only for work operations. Task creation and work messages are manager-only at the backend. Employees can only update/submit their own assigned tasks.
- Existing SQLite databases are upgraded automatically with the new message fields; new tables are created at startup.
