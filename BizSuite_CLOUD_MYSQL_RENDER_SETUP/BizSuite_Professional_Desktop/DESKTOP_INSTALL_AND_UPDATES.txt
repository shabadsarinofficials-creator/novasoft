BizSuite Professional Desktop 1.3.0 — Quick Setup

First, extract the ZIP to a permanent folder such as C:\BizSuite_Professional_Desktop (do not run it from Downloads and move it later, because the server auto-start task points to this folder). Use these launchers from that folder:

1. On the computer that will host company data, double-click run_admin.bat. First run checks prerequisites, prepares the backend, prompts for the initial administrator email/password only if the database does not exist, starts the API in the background, attempts to register server auto-start at Windows sign-in, builds/installs BizSuite Admin, and launches it.
2. On each manager PC, double-click run_manager.bat. First run installs BizSuite Manager and launches it. Enter the host computer's server URL when prompted, such as http://192.168.1.25:8000.
3. On each employee PC, double-click run_employee.bat. First run installs BizSuite Employee and launches it. Enter the same server URL.
4. All three apps have distinct Windows app identities, icons, Start Menu shortcuts, and desktop shortcuts. After installation, use the installed shortcuts; the BAT files can also be used as setup/repair launchers. Pin the app to the taskbar by right-clicking its running taskbar icon and choosing Pin to taskbar.

First setup can take several minutes and needs internet access to download Node.js/Python runtimes and packages. The app installer build is per-user, so it should not need Administrator rights. If Windows Firewall prompts on the host, allow the API only on trusted Private networks. Do not expose port 8000 directly to the public internet.

Server: the Admin PC runs the shared API on port 8000 and stores data in backend\bizsuite.db and uploaded files in backend\uploads. Keep this PC on while others are using BizSuite. Server logs: backend\server.log. If the server auto-start task cannot be registered, run install-server-autostart.bat after first setup.

Existing data: before upgrading, back up the entire BizSuite folder. Preserve backend\bizsuite.db, backend\jwt.secret, and backend\uploads. Never replace these with a blank database.

Software update feed: automatic binary updates are not activated until you configure a real release repository/feed and set BIZSUITE_UPDATE_FEED_CONFIGURED=1 for the installed apps. Do not set that variable until the release feed is valid. Task/message synchronization is separate and uses the shared server.
